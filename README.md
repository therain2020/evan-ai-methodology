# Evan's AI Methodology

> Not a setup guide. Notes from building an AI dev workflow. Got plenty wrong, changed my mind a lot, wrote down what stuck.
>
> [中文版本](README_zh.md)

[evan-ai-setup](https://github.com/therain2020/evan-ai-setup) has the install scripts. This repo has the design notes. Read both if you want the full picture.

## Who This Is For

If you've been using AI coding tools and "faster" stopped meaning "better" — you might find something here. I wrote it for the moment when you realize the AI can do more than just type.

## Reading Order

Start with Chapter 1, then 2. Debugging something: jump to 4. Building a skill: 6. Setting up review gates for a team: 7. No hard dependencies — skip around.

## What This Is

Not a textbook. Field notes. I got stuck, changed my mind, rewrote things, and kept what survived. This space moves too fast for definitive answers. It's a work log from when AI dev tools went mainstream and everyone was figuring it out at the same time.

If your experience is different, I might be wrong — or we just have different setups. Issues welcome.

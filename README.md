# Evan's AI Methodology

> 中文摘要：不是"如何安装"，而是"为什么这样用"——AI 辅助开发的思维框架、工作流设计原则、踩过的坑和积累的方法论。

This is the companion volume to [evan-ai-setup](https://github.com/therain2020/evan-ai-setup). That repo tells you *how* to install. This one tells you *why* it works that way.

## Who This Is For

Developers who already use AI coding tools and want to go from "AI helps me write code faster" to "AI is a thinking partner that makes my architecture better."
